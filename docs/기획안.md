# Smart Factory Vision AI
## 자동차 생산 라인 이미지 기반 실시간 불량 판별 시스템 구축 프로젝트

---

# 1. 프로젝트 개요

## 1.1 프로젝트명

Smart Factory Vision AI  
자동차 도어 이미지 기반 실시간 불량 판별 시스템

## 1.2 프로젝트 목적

본 프로젝트는 자동차 생산 라인에서 생산되는 **자동차 도어 이미지를 카메라로 촬영하여 AI 기반 이미지 분석 모델을 통해 불량 여부를 자동으로 판별하는 시스템을 구축하는 것을 목표로 한다.**

이를 통해 다음과 같은 기능을 구현한다.

- 생산 공정 중 **불량 제품 실시간 탐지**
- 이미지 내 **불량 발생 위치 시각화**
- 검사 결과 **데이터베이스 저장**
- 생산 및 불량 현황 **실시간 대시보드 시각화**

본 시스템은 **스마트팩토리 환경에서 활용 가능한 AI 기반 비전 검사 시스템의 기본 구조(PoC)를 구현하는 것을 목표로 한다.**

---

# 2. 추진 배경

자동차 제조 공정에서는 도어, 차체, 부품 등 다양한 부품에 대해 품질 검사를 수행한다.

기존 방식은 다음과 같은 문제점이 존재한다.

- 검사 인력 의존도가 높음
- 검사 속도 한계
- 검사 결과 데이터 축적 부족
- 실시간 품질 대응 어려움

최근 스마트팩토리에서는 **컴퓨터 비전 기반 자동 검사 시스템**을 활용하여 제품 이미지를 분석하고 불량 여부를 자동으로 판단하는 기술이 확대되고 있다.

따라서 본 프로젝트에서는

**카메라 기반 이미지 수집 → AI 분석 → 결과 저장 → 실시간 대시보드 시각화**

까지의 **통합 비전 검사 시스템 구조를 구현한다.**

---

# 3. 자동차 도어 규격 및 생산 라인 가정

## 3.1 자동차 도어 평균 규격

일반적인 승용차 기준 자동차 도어 크기는 다음과 같다.

| 항목 | 평균 크기 |
|-----|-----------|
| 가로 | 약 1100 ~ 1300 mm |
| 세로 | 약 900 ~ 1100 mm |
| 두께 | 약 120 ~ 180 mm |

평균 기준

```
약 1.2 m × 1.0 m
```

---

## 3.2 자동차 생산 라인 컨베이어 평균 속도

자동차 조립라인 컨베이어 속도는 공장마다 차이가 있지만 일반적으로 다음 범위이다.

| 구분 | 속도 |
|----|----|
| 느린 라인 | 약 3 m/min |
| 빠른 라인 | 약 6 m/min |

초 기준 환산

```
3 m/min  = 0.05 m/s
6 m/min  = 0.1 m/s
```

---

## 3.3 도어 검사 구간 통과 시간

자동차 도어 길이를 약 **1.2m**로 가정할 경우

느린 라인

```
1.2 / 0.05 ≈ 24초
```

빠른 라인

```
1.2 / 0.1 ≈ 12초
```

따라서 자동차 도어가 검사 구간을 통과하는 시간은

```
약 12 ~ 24초
```

이다.

본 프로젝트에서는 실제 생산 공정과 유사한 환경을 고려하여

```
자동차 도어 이미지 데이터를 12초 간격으로 생성 및 전송
```

하도록 시스템을 설계한다.

---

# 4. 시스템 시나리오

본 시스템은 다음과 같은 생산 라인을 가정한다.

1. 컨베이어 벨트를 통해 자동차 도어가 이동
2. 도어가 검사 구간을 통과할 때 카메라가 이미지를 촬영
3. 촬영된 이미지를 서버로 전송
4. AI 모델이 이미지 분석 수행
5. 불량 여부 및 불량 위치 판별
6. 검사 결과를 데이터베이스에 저장
7. 결과를 실시간 대시보드에 표시

데이터 전송 주기

```
12초마다 자동차 도어 이미지 데이터 전송
```

# 6. 주요 기능

## 6.1 이미지 데이터 수집

생산 라인의 카메라 촬영 환경을 시뮬레이션한다.

기능

- 이미지 데이터 생성
- 컨베이어 이동 환경 시뮬레이션
- 12초 간격 이미지 전송

모듈

```
camera_simulator
```

---

## 6.2 AI 기반 불량 판별

컴퓨터 비전 모델을 활용하여

- 정상 제품
- 불량 제품

을 분류한다.

또한 단순 분류뿐 아니라

**이미지 내 불량 발생 위치를 탐지하여 Bounding Box 형태로 표시한다.**

기능

- 이미지 전처리
- 모델 추론
- 불량 여부 판정
- 불량 위치 탐지
- 불량 영역 시각화

모듈

```
model
```

---

## 6.3 API 서버 처리

FastAPI 기반 서버를 통해 다음 기능을 수행한다.

- 이미지 데이터 수신
- AI 모델 추론 요청
- 검사 결과 반환
- 데이터베이스 저장

모듈

```
api
```

---

## 6.4 데이터 저장

검사 결과 데이터를 데이터베이스에 저장한다.

저장 정보

- 제품 ID
- 이미지 경로
- 검사 시간
- 불량 여부
- 모델 신뢰도
- 불량 위치 좌표 (Bounding Box)

모듈

```
database
```

---

## 6.5 실시간 대시보드

Streamlit 기반 대시보드를 통해 다음 정보를 시각화한다.

- 생산 수량
- 불량 발생 현황
- 불량률
- 최근 검사 이미지
- 불량 위치 표시 이미지

모듈

```
dashboard
```
