> **용어 설명**
> - **Precision**: 불량이라고 예측한 것 중 실제 불량인 비율
> - **Recall**: 실제 불량을 얼마나 놓치지 않고 찾아냈는지의 비율
> - **mAP50**: 정답과 50% 이상 겹쳤을 때의 평균 정밀도 (핵심 지표)
